赵何伟 · 个人影像博客

1. 直接双击 index.html 在本地浏览。项目不依赖在线 CDN 或后端。
2. index.html 包含日记时间轴、照片墙、视频、致敬文章与关于内容。
3. style.css 是黑白灰与少量蓝色的响应式样式；main.js 负责照片预览和导航提示。
4. assets/ 保留八张照片与两张视频封面；videos/ 共十段原始 MP4，均未重新压缩。五段朋友圈视频放在时间轴，其余五段放在视频区。
5. 部署到 GitHub Pages 时，将 friend-blog 文件夹内容放在发布目录根部。
6. 时间轴保留已明确的 2024 年日期；仅有月日的动态归入“生活随记”，不推测年份。没有实际内容的空动态未展示。
7. 公开发布前，请确认照片和视频中相关人员同意公开。
